Tutorial Penggunaan

Panduan lengkap untuk mengkonfigurasi dan menggunakan Dashboard E-Resources PKN STAN.

1. Menghubungkan sumber data

Keempat layanan membaca data dari Google Sheets melalui Google Apps Script. File Excel atau CSV perlu diimpor ke Google Sheets terlebih dahulu; dashboard tidak menyediakan unggah file langsung.

  1. Buka Google Sheets yang berisi data layanan. Pastikan format kolom sesuai tabel panduan di bawah.
  2. Buka Extensions → Apps Script. Gunakan kode penghubung untuk layanan yang sesuai dari folder apps-script proyek ini.
  3. Deploy sebagai Web app, dijalankan sebagai pemilik spreadsheet. Gunakan pengaturan akses sesuai lingkungan pemasangan Anda.
  4. Salin URL deployment yang berakhiran /exec.
  5. Buka halaman layanan di dashboard → Konfigurasi URL → masukkan URL → Hubungkan.

Pengaturan URL disimpan pada browser dan perangkat yang digunakan. Setelah kode Apps Script diubah, perbarui deployment ke versi baru agar perubahan berlaku.

2. Format data tiap layanan

E-Journal

Gunakan laporan COUNTER dengan header Title, Metric_Type, Reporting_Period_Total, lalu kolom bulan seperti Jan-2026. Penghubung mencari header Title dalam 30 baris pertama dan membaca kolom bulan setelah total. Secara bawaan sheet pertama yang digunakan.

Tambahkan periode tanpa menggandakan laporan yang sudah ada. Data agregat jurnal tidak menyediakan identitas pengguna, sehingga rincian pengguna tidak ditampilkan untuk layanan ini.

LSEG

Kolom D: NIP/NIM; E: email; F: prodi; H: tanggal penggunaan; J: tujuan. Nama sheet yang dicari adalah lseg user, kemudian Form Responses 1, atau sheet pertama.

STATA

Kolom A: waktu pengajuan; B: nama; C: NIP/NIM/NIK; D: email; E: prodi/unit; F: kebutuhan. Gunakan sheet Form Responses 1 atau sheet pertama.

Uji Similaritas KTI

Penghubung juga mengenali Details Report enam kolom: User first name, User last name, User email, Date processed, Words count, dan Similarity score. Pertahankan header aslinya saat diimpor ke Google Sheets. Laporan ini menyediakan tanggal, nama pengguna, dan skor, tetapi tidak memuat NIM atau judul KTI; dashboard menandai bagian tersebut sebagai tidak tersedia.

Kolom A: tanggal; B: NIM; C: nama; E: jenis KTI; F: judul; G: similaritas; H: status opsional. Secara bawaan sheet pertama digunakan.

Similaritas dapat berupa angka 30, teks 30%, atau sel berformat persentase. Hasil kosong/tidak valid ditampilkan tanpa angka dan mendapat status Proses jika status belum diisi. Nilai 0% tetap dihitung sebagai hasil yang sah.

Gunakan kode KTI terbaru dalam proyek ini agar sel persentase dan hasil kosong diproses dengan benar. Perbarui deployment setelah mengganti kodenya.

3. Membaca statistik

  • Home memakai metrik Total_Item_Requests untuk akses E-Journal.
  • Total penggunaan LSEG/STATA adalah jumlah catatan penggunaan. Pengguna unik dihitung dari NIP/NIM yang terisi, setelah filter diterapkan.
  • Kategori pengguna mengikuti aturan awalan NIP/NIM yang ada: 19 untuk dosen, 3 atau 4 untuk mahasiswa, dan lainnya untuk identitas lain. Ini merupakan klasifikasi otomatis yang perlu diperiksa terhadap data sumber.
  • Total aktivitas layanan menjumlahkan akses jurnal, catatan LSEG/STATA, dan pengajuan KTI. Angka ini bukan jumlah orang unik.
  • Status KTI yang diisi pada spreadsheet dipertahankan. Jika kosong, aturan aplikasi adalah ≤30% Lolos, >30–50% Revisi, dan >50% Tidak Lolos. Batas ini perlu disesuaikan bila kebijakan layanan berubah.
  • Rata-rata similaritas menghitung hasil numerik yang sah, termasuk 0%; hasil kosong dikecualikan. Grafik status tetap menyertakan pengajuan yang masih diproses atau berstatus lain.

4. Pembaruan, filter, dan ekspor

Perbarui data di spreadsheet, kemudian tekan Perbarui data untuk mengambil data langsung. Dashboard menggunakan cache hingga 30 menit ketika halaman dibuka biasa.

  • Terbaru: data berhasil diambil dari sumber.
  • Tersimpan: data diambil dari cache browser.
  • Data lama: pengambilan terbaru gagal, data sebelumnya tetap ditampilkan.
  • Gagal: sumber gagal dimuat dan tidak ada cache yang cocok.

Status sumber tampil sebagai label kecil di samping tombol tindakan. Klik label untuk melihat waktu pengambilan dan pesan kendala. Klik di luar rincian atau tekan Escape untuk menutupnya.

Gunakan filter tahun, kategori, metrik, atau pencarian yang tersedia. Filter prodi tersedia pada menu LSEG dan STATA. Tekan Reset filter untuk mengembalikan pilihan. Ekspor CSV mengunduh semua baris yang cocok dengan filter, termasuk baris pada halaman tabel berikutnya.

CSV dapat dibuka di aplikasi spreadsheet. Saat mengimpor identitas NIP/NIM, pilih tipe kolom teks untuk mempertahankan angka panjang dan nol di awal.

5. Mengatasi kendala

  • Sumber tidak tersedia: periksa URL /exec, koneksi internet, akses deployment, dan pesan pada kartu sumber. Coba Perbarui data.
  • Data kosong: periksa sheet yang dibaca dan pastikan baris header serta pemetaan kolom sesuai.
  • Grafik gagal dimuat: periksa koneksi ke penyedia pustaka grafik, kemudian muat ulang halaman.
  • Tanggal tidak masuk filter: gunakan sel tanggal valid atau format DD/MM/YYYY. Tanggal yang tidak valid tidak dimasukkan ke tren bulanan.
  • Login mengalami kesalahan sistem: akses melalui HTTPS atau server lokal localhost agar fungsi pemeriksaan sandi tersedia.
